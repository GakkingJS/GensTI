# Pruebas SABER PRO y requisitos de graduación

FUENTE: https://ucc.edu.co/campus-ibague-espinal/Paginas/grados.aspx
FECHA_DE_VERIFICACION: 2026-11-19
ALCANCE: Estudiantes de pregrado / Campus Ibagué
ESTADO: Verificado

## ¿SABER PRO es requisito para graduarse?

Sí. Para estudiantes de pregrado, presentar las Pruebas SABER PRO es un
requisito para graduarse.

Al solicitar la auditoría para grado, debes cargar el resultado o certificado
de presentación de las Pruebas SABER PRO.

## Encuesta OLE

También debes cargar el certificado de la encuesta OLE, correspondiente al
Observatorio Laboral para la Educación.

La encuesta se realiza en:

https://www.graduadoscolombia.edu.co/encuesta/

## Trabajo de grado

Cuando corresponda, debes autoarchivar el trabajo de grado en el Repositorio
Institucional de la UCC:

https://repository.ucc.edu.co/

## Fechas

Las fechas de solicitud de auditoría, graduación y demás etapas dependen del
cronograma de cada ceremonia de grado.

Puede haber calendario A y calendario B, según las fechas establecidas por
el ICFES y la Universidad.

## Restricciones

- No inventar fechas de SABER PRO.
- No confirmar exenciones sin fuente oficial.
- Si el estudiante tiene dudas sobre su caso, remitirlo a DARC o a la
  coordinación de Ingeniería de Sistemas.
